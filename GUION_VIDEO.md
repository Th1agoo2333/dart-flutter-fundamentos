# GUION PARA EL VIDEO

## Presentación
“Mi nombre es Santiago González. En este video presentaré la evidencia de la actividad de fundamentos de programación con Dart y Flutter. Mostraré el repositorio, los commits, las ramas, los ejercicios desarrollados y las principales dificultades del proceso.”

## Repositorio
“Este es mi repositorio personal `dart-flutter-fundamentos`. En la rama principal se encuentra la versión final. También creé las ramas `desarrollo` y `evidencia-final` para evidenciar el proceso. El historial contiene commits separados para la estructura, los ejercicios, la aplicación Flutter y la documentación.”

## Código
“En la carpeta `bin` se encuentran quince ejercicios. Se utilizan lectura de datos, validaciones, condicionales, ciclos, listas, expresiones regulares, funciones y operaciones matemáticas. En `lib/main.dart` se encuentra una aplicación Flutter básica con una lista de los temas estudiados.”

## Cuatro dificultades mínimas
1. “La primera dificultad fue diferenciar Dart de Flutter. Dart es el lenguaje con el que resolví la lógica; Flutter es el framework con el que construí la interfaz.”
2. “La segunda dificultad fue validar las entradas. Utilicé `tryParse` para evitar que el programa falle si se escribe un valor que no es numérico.”
3. “La tercera dificultad fue controlar casos especiales, por ejemplo, impedir una división entre cero y evitar calcular factoriales de números negativos.”
4. “La cuarta dificultad fue manejar Git y GitHub. Separé el trabajo en ramas y commits para conservar evidencia del proceso de desarrollo.”
5. Opcional: “Otra dificultad fue simplificar fracciones. Implementé una función de máximo común divisor para entregar el resultado reducido.”

## Demostración
Ejecuta y explica, como mínimo:
- Ejercicio 1 con `5` y luego `-4`.
- Ejercicio 8, cuyo resultado esperado es `650`.
- Ejercicio 14 con `5`, cuyo resultado esperado es `120`.
- `flutter run` para mostrar la aplicación.
