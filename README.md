# Fundamentos de programación con Dart y Flutter

**Estudiante:** Santiago González  
**Objetivo:** Evidenciar el manejo de GitHub, lógica de programación, programación orientada a objetos y una aplicación inicial en Flutter.

## Contenido
- `bin/`: 15 ejercicios independientes en Dart.
- `lib/main.dart`: aplicación Flutter básica que presenta los temas estudiados.
- `GUIA_PASO_A_PASO.md`: instrucciones para configurar, probar y publicar el proyecto.
- `GUION_VIDEO.md`: guion sugerido para la sustentación.

## Ejecución
```bash
dart run bin/ejercicio_01_positive_power.dart
flutter pub get
flutter run
```

## Evidencias requeridas
- Repositorio personal en GitHub.
- Commits del proceso.
- Branches del desarrollo.
- Video explicando como mínimo cuatro dificultades y mostrando el código.
